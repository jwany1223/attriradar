컴퓨터는 색을 빨강·초록·파랑의 양(RGB)으로 저장합니다. 그런데 "빨간 옷"을 판정하려면 사람이 말하는 방식이 필요합니다. 그래서 먼저 HSV로 바꿉니다.

function rgbToHsv(r,g,b){
  const mx=Math.max(r,g,b),
        mn=Math.min(r,g,b),
        d=mx-mn;
  …
  return [h, d/mx, mx/255];
}
색의 좌표계를 바꾼다 세 숫자를 돌려줍니다. H(색상) 어떤 색인가 — 0~360도의 각도. 빨강 0도, 초록 120도, 파랑 240도.
S(채도) 얼마나 선명한가 — 0이면 무채색.
V(명도) 얼마나 밝은가 — 0이면 검정.

가장 큰 값과 가장 작은 값의 차이(d)가 선명함을 결정합니다. 회색은 셋이 비슷해서 차이가 0입니다.

function iou(a,b){
  const x0=Math.max(a.x,b.x),
        y0=Math.max(a.y,b.y),
        x1=Math.min(a.x+a.w, b.x+b.w),
        y1=Math.min(a.y+a.h, b.y+b.h);
  const inter=Math.max(0,x1-x0)
             *Math.max(0,y1-y0);
  const u=a.w*a.h + b.w*b.h - inter;
  return inter/u;
}
두 상자가 얼마나 겹치나 IoU = 겹친 넓이 ÷ 합친 넓이.

inter가 겹친 부분, u가 둘을 합친 부분입니다. 합칠 때 겹친 부분을 한 번 빼는 이유는 두 번 세지 않기 위함입니다.

결과는 0~1. 완전히 포개지면 1, 안 닿으면 0. 이전 프레임의 상자와 지금 상자가 0.2 이상 겹치면 같은 사람으로 봅니다.

function pushVote(t,v,N){
  t.hist.push(v?1:0);
  while(t.hist.length>N) t.hist.shift();
}
function sumVotes(t){
  let s=0;
  for(const v of t.hist) s+=v;
  return s;
}
