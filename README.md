# AttriRadar — 속성 인식 경보 에이전트

휴대폰 카메라로 사람·차량을 인식하되, **아무나가 아니라 속성으로 걸러서** 경고하는 웹앱입니다.
사람은 상의 색과 모자 착용 여부, 차량은 차체 색과 차종으로 구분합니다.

---

## 1. 그냥 써보기 — 제일 빠름

휴대폰 브라우저로 아래 주소를 엽니다. **설치 필요 없습니다.**

```
https://__아이디__.github.io/attriradar/
```

> 👆 이 자리에 실제 주소를 적어서 공유하세요.

1. **시작** 버튼 → 카메라 **허용**
2. 조건 입력란에 `빨간 옷 입은 사람` 처럼 문장으로 입력
3. 빨간 옷 입은 사람을 비추면 경고음

**아이폰은 사파리**, **안드로이드는 크롬**으로 여세요.
아이폰은 웹 진동을 지원하지 않아 소리·음성·화면 배너로만 알립니다. 고장이 아닙니다.

## 2. 코드 보기

이 폴더의 **`코드설명.html`** 을 더블클릭하면 브라우저로 열립니다.

왼쪽에 실제 코드, 오른쪽에 그 뜻이 적혀 있습니다. 프로그래밍을 몰라도 읽을 수 있게 써뒀습니다.
발표에서 코드 질문이 나올 때 대비용으로도 쓸 수 있습니다.

### 파일 하나에 전부 들어 있습니다

`index.html` 1355줄 안에 화면·디자인·동작이 다 있습니다.

| 구역 | 줄 | 무엇 |
|---|---|---|
| CSS | 13~209 | 어떻게 보이는지 |
| HTML | 211~431 | 화면에 무엇이 있는지 |
| JavaScript | 432~1353 | 실제 동작 |

**발표에서 설명할 부분은 432~700줄뿐**입니다.
코드에 `/*CORE-START*/` ~ `/*CORE-END*/` 로 표시해뒀습니다.

---

## 3. 내 컴퓨터에서 돌려보기

코드를 고쳐보려면 이렇게 합니다. **파일을 더블클릭하면 카메라가 안 켜집니다** —
브라우저가 안전한 주소에서만 카메라를 허용하기 때문입니다.

### 맥

터미널에서 한 줄씩:

```
cd ~/Downloads/attriradar
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속. 끌 때는 터미널에서 `control` + `C`.

### 윈도우

명령 프롬프트에서:

```
cd %USERPROFILE%\Downloads\attriradar
python -m http.server 8000
```

같은 주소로 접속. 파이썬이 없다면 python.org에서 설치하세요.

## 4. 구조 — 네 단계로 거릅니다

```
① 탐지      MediaPipe EfficientDet
             사람 · 승용차 · 트럭 · 버스 · 오토바이
     ↓
② 속성 판정  박스 안 화소를 HSV로 분류
             상의 색 · 차체 색 · 모자 착용
     ↓
③ 추적·투표  IoU로 같은 대상 추적
             최근 6프레임 중 4번 맞아야 확정
     ↓
④ 경보      소리 · 음성 · 배너, 같은 대상 8초 쿨다운
```

**②가 기준 앱에 없는 부분**이고, **③이 오탐을 줄이는 부분**입니다.

---

## 5. 비교 측정은 이렇게 합니다

설정에서 **비교 모드**를 켜면 색·모자를 보지 않고 범주만으로 즉시 경보합니다.
= 기준 앱(Smart Motion Radar) 방식의 재현입니다.

같은 영상을 세 번 돌려 비교합니다.

| 조건 | 설정 | 조건문 |
|---|---|---|
| **B** 기준 앱 재현 | 비교 모드 켬, 최대 탐지 5 | `사람` |
| **C** 속성만 | 비교 모드 끔, 투표 1/1 | `빨간 옷 입은 사람` |
| **D** 전체 기능 | 비교 모드 끔, 투표 4/6 | `빨간 옷 입은 사람` |

**영상 파일을 앱에 직접 불러오세요**(테스트 영상 버튼).
카메라로 모니터를 비추면 화질이 떨어져 조건이 오염됩니다.

경보가 울릴 때마다 **정답 / 재경보 / 오탐** 중 하나를 누르면
정밀도·재현율·분당 오탐이 자동 계산되고 CSV로 저장됩니다.

> 시작 전 **목표 대상 수** 칸에 "영상 속 빨간 옷 입은 사람 수"를 입력해야
> 재현율이 계산됩니다.

## 6. 안드로이드 쓰는 조원에게 부탁

기준 앱 **Smart Motion Radar** 가 Google Play 전용이라 아이폰에서는 설치가 안 됩니다.
안드로이드를 쓰신다면 설치해서 아래만 확인해 주세요. 발표 자료에 들어갑니다.

- [ ] 사람이 지나갈 때 **같은 사람에게 몇 번** 울리는지
- [ ] 옷 색을 구분하는 설정이 **정말 없는지**
- [ ] 동시 탐지 상한이 **5개가 맞는지**
- [ ] 화면 캡처 2~3장

---

## 7. 알려진 한계

| 상황 | 증상 | 대응 |
|---|---|---|
| 검은 모자 | 잘 못 잡음 | 머리카락과 화소 수준에서 구분 불가. 흰 모자·안전모는 잘 됨 |
| 밝은 역광 | 모자로 오인 | 머리 위로 창문·천장이 들어오면 발생 |
| 너무 가까이 | 상의가 갈색으로 | 목·어깨 피부가 상의 영역에 들어옴. **2~3m 떨어지면 해결** |

시연할 때는 **2~3m 떨어져서 상반신 이상이 들어오게** 하고,
모자는 **흰색이나 안전모**를 쓰는 게 안전합니다.
